# PWA Icons

This directory should contain the following icon sizes for optimal PWA support:

## Required Icons

- `icon-72.png` - 72x72px
- `icon-96.png` - 96x96px
- `icon-128.png` - 128x128px
- `icon-144.png` - 144x144px
- `icon-152.png` - 152x152px
- `icon-192.png` - 192x192px (Android)
- `icon-384.png` - 384x384px
- `icon-512.png` - 512x512px (Android, maskable)

## Generating Icons

You can use tools like:
- [PWA Asset Generator](https://github.com/elegantapp/pwa-asset-generator)
- [RealFaviconGenerator](https://realfavicongenerator.net/)
- Or create them manually with your preferred design tool

## Icon Design Recommendations

- Use the treasure chest / pirate theme (🏴‍☠️)
- Ensure good contrast for both light and dark backgrounds
- Make icons simple and recognizable at small sizes
- Consider using a maskable icon for Android adaptive icons
